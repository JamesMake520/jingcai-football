## 1. 五大玩法

### 胜平负 (WDL)
预测90分钟(含伤停补时,不含加时/点球)的结果:胜(3)、平(1)、负(0)。数字3/1/0是投注代码。

### 让球胜平负 (Handicap WDL)
官方给主队设定一个让球数(如 -1,即主队让一球),在主队净胜球基础上加上让球数后再判定胜平负。
- 例:主队让1球(-1),实际比分2:1 → 调整后2:(1+1)=2:2 → 让球结果为"平"。
- 让球数由官方设定,固定不变(不同于亚盘的浮动盘口)。

### 比分 (CS)
预测90分钟准确比分。胜方向13种(1:0到5:2等)+ 胜其他;平方向5种(0:0,1:1,2:2,3:3)+ 平其他;负方向13种 + 负其他。共31个选项(含3个"其他")。

### 总进球 (Goals)
预测90分钟两队总进球数:0、1、2、3、4、5、6、7+,共8个选项。

### 半全场 (HT/FT)
预测半场结果与全场结果的组合,3×3=9个选项:胜胜、胜平、胜负、平胜、平平、平负、负胜、负平、负负。

## 2. 让球的语义(易错点)

- "让球胜"= 主队在让球后仍获胜。主队让1球时,"让球胜"要求主队净胜2球及以上。
- 主队受让(让球数为正,如+1)时,"让球胜"门槛降低:主队输0:1也算让球平,踢平即让球胜。
- **分析时必须先确认该场官方让球数**,再讨论让球方向,不能把胜平负的判断直接平移过去。

## 3. 串关规则

- 过关方式记作 M串N:选M场比赛,N表示拆分出的投注组合数。
- 最常见的是 **M串1**(2串1到8串1):所有场次全对才中奖,奖金 = 本金 × 各场SP连乘。
- 复合过关如 3串4 = 3个2串1 + 1个3串1,部分命中也可中部分奖金,但本金按注数倍增。
- 同一场比赛的不同玩法一般不能互相串(同场不可串关,具体以官方规则为准)。
- 单注最高限额与奖金封顶以官方规则为准(历史上单票奖金上限50万元,需搜索确认现行规定)。

## 4. SP(赔率)与返还率

- 竞彩为固定奖金制,购票时锁定当时SP。
- 官方SP含水位:胜平负返还率通常仅约72-78%(欧赔主流公司约94-97%)。这意味着:
  - 直接用竞彩SP的倒数求和会得到约1.30+的总和(欧赔约1.03-1.06)。
  - **价值判断要用去水后的隐含概率**(脚本 `implied` 命令自动处理)。
  - 同样的判断,长期在竞彩投注的理论损耗远高于低水盘口,这是提醒用户控制投入的客观依据。

## 5. 单关与过关限制

- 部分场次开放"单关"(可单场投注),多数场次要求至少2场过关。
- 哪些场次开单关由官方决定,通常是焦点赛事。分析前先确认目标场次是否可单关,否则推荐方案要按2串1起步设计。

## 6. 常用术语表

| 术语 | 含义 |
|---|---|
| 胆 | 串关中最有把握、固定不变的场次 |
| 拖 | 围绕胆的多个备选场次/选项 |
| 冷门 | 低概率高赔结果 |
| 走盘 | (亚盘语境)盘口结果为和,退还本金;竞彩固定让球无走盘 |
| 初盘/即时盘 | 开盘时赔率 / 临场实时赔率 |
| 凯利指数 | 衡量某选项赔付风险的指标,>1常被解读为该方向有支持 |
| 必发 | 必发交易所成交量数据,反映大额资金方向 |

# 竞彩分析框架

分析 = 基本面(得出主观概率) + 赔率面(得出市场概率) + 两者对比(找价值)。

## 1. 基本面分析清单

按重要性排序,每场比赛逐项过:

**A. 近期状态(权重高)**
- 近5-6场胜平负、进失球,区分主客场(主客差异大的队很常见)
- 状态趋势:是连胜中还是刚崩盘?对手强度如何(赢弱队5场≠状态好)

**B. 阵容与伤停(权重高)**
- 核心球员(主力前锋、中场组织者、主力门将、中卫)是否缺席
- 一个顶级前锋缺阵可让预期进球降0.3-0.5球;主力门将缺阵影响同样显著

**C. 比赛动机(权重中高,越到赛季后期越重要)**
- 保级队 vs 无欲无求的中游队:动机差可以逆转实力差
- 双线作战球队在杯赛前后联赛轮换是常态
- 已出线/已降级球队的比赛极难预测,建议回避

**D. 交锋历史(权重中低)**
- 仅作参考。近5次交锋,注意阵容是否已大换血
- 个别"克星"关系(战术相克)值得加分

**E. 其他**
- 赛程密度(一周三赛第3场体能下滑)、长途客场、天气/场地、新帅效应

## 2. 主观概率估计方法

两种方法,建议都做并交叉验证:

**方法1:直接估计**
基于上面的清单,直接给出主胜/平/客胜百分比(总和=100%)。锚点参考:
- 势均力敌的比赛:主35% / 平30% / 客35% 附近
- 主队明显强:55% / 25% / 20% 起步
- 平局概率很少超过35%,也很少低于18%(超强弱对话除外)

**方法2:泊松模型**
1. 估计两队本场预期进球(参考赛季场均进失球,调主客场、伤停、对手强度)
2. 运行 `python scripts/jc_calc.py poisson <主队预期进球> <客队预期进球>`
3. 脚本输出胜平负概率、各比分概率、总进球分布——直接覆盖比分和总进球玩法

两法结果差异大时,说明有结构性因素(动机、轮换)泊松没捕捉到,以调整后的直接估计为准。

## 3. 赔率面分析

1. **去水**:`python scripts/jc_calc.py implied <胜赔> <平赔> <负赔>` 得到市场隐含概率
2. **多源对比**:竞彩SP vs 欧赔主流公司(威廉/Bet365/立博)。竞彩明显高于欧赔同方向折算赔率→竞彩在该方向给了相对价值;明显低→官方在防范该方向
3. **赔率变化**:初盘→即时盘。某方向赔率持续走低=市场资金/信息流向该方向。临场大幅变盘要警惕突发信息(首发公布、关键伤停)
4. 若有必发数据:大额成交集中方向可作辅助佐证,不作主要依据

## 4. 价值判断与下注决策

核心公式:**EV = 主观概率 × 赔率 − 1**

- EV > 0:有价值。但竞彩水位深,主观概率的估计误差通常有±5%,**建议只把 EV > +8% 视为可操作的价值点**
- 用 `kelly` 命令算仓位,默认输出1/4凯利(全凯利波动太大,业余玩家必爆)
- 置信度标注:
  - 高:基本面与赔率面指向一致,且EV>8%
  - 中:基本面有支持但赔率面中性
  - 低:仅一面支持或信息不全 → 报告中明确建议放弃或小注娱乐

**串关纪律:**
- 整体命中率 = 各场概率连乘,场次越多越接近买彩票。给用户算清楚再让他决定
- 胆的标准:主观概率≥65%且无重大伤停/轮换不确定性
- 3场以上的串关,建议展示"全包成本 vs 期望回报",多数情况会发现不划算

## 5. 玩法选择建议

| 判断场景 | 适合玩法 |
|---|---|
| 强弱分明,强队赔率太低没价值 | 让球胜平负(看让球后是否仍有价值) |
| 对总进球有把握(攻强守弱/双弱攻) | 总进球(用泊松输出选区间) |
| 判断比赛走势(先抑后扬等) | 半全场(高赔,小注) |
| 泊松显示某2-3个比分概率突出 | 比分小复式 |
| 只确定"不败"不确定胜 | 平/胜双选,或让球受让方向 |

## 6. 常见错误清单(输出前自查)

- [ ] 没搜最新伤停就下结论(训练数据是旧的!)
- [ ] 把名气当实力(豪门低谷期、升班马开局热都是赔率陷阱)
- [ ] 概率总和≠100%
- [ ] 用含水赔率直接当概率
- [ ] 让球方向和胜平负方向混着说
- [ ] 推荐了平局概率>30%的比赛做胆
- [ ] 报告没有风险点和理性购彩提示

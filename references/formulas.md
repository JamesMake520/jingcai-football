# 手算公式参考(无代码执行环境时使用)

> 当运行环境无法执行Python脚本时,按本文件公式逐步计算,**必须在回复中展示中间步骤**,方便用户核对。所有公式与 `scripts/` 下脚本的逻辑完全一致。

## 1. 赔率 → 去水隐含概率

设三项赔率为 O胜, O平, O负:
```
原始概率: r胜 = 1/O胜,  r平 = 1/O平,  r负 = 1/O负
水位总和: S = r胜 + r平 + r负   (竞彩通常 1.15~1.35)
返还率:   1/S
去水概率: p胜 = r胜/S,  p平 = r平/S,  p负 = r负/S
```
例: 2.10 / 3.20 / 3.40 → r = 0.476/0.313/0.294, S=1.083 → 去水 44.0%/28.9%/27.2%

## 2. 期望值 EV

```
EV = 主观概率 × 赔率 − 1
```
判定: EV > +8% 才视为可操作的价值点(留出估计误差余量);0~8% 谨慎;<0 放弃。

## 3. 凯利仓位

```
b = 赔率 − 1
全凯利比例 f = (p × b − (1−p)) / b      (p为主观概率)
建议仓位 = f / 4   (1/4凯利)
```
f ≤ 0 时无优势,不投。例: p=0.52, 赔率2.10 → b=1.1, f=(0.572−0.48)/1.1=8.4%, 建议仓位2.1%。

## 4. 串关(M串1)

```
总赔率 = 各场SP连乘
整体命中率 = 各场主观概率连乘
组合EV = 整体命中率 × 总赔率 − 1
```
任何一场单场EV为负,串入都会拉低组合EV,先剔除再算。

## 5. 简化泊松(估比分/总进球分布)

设主队预期进球 λh,客队 λa。单边进 k 球的概率:
```
P(k) = e^(−λ) × λ^k / k!
```
手算时只需算 k=0..4(覆盖95%+场景),列出5×5比分矩阵:格子(i,j)概率 = Ph(i)×Pa(j)。
- 主胜概率 ≈ 矩阵中 i>j 格子之和;平局 ≈ 对角线之和;客胜 ≈ i<j 之和
- 总进球n球概率 ≈ 所有 i+j=n 格子之和
- e^(−λ) 速查: λ=0.8→0.449, 1.0→0.368, 1.2→0.301, 1.4→0.247, 1.6→0.202, 1.8→0.165, 2.0→0.135
- 修正: 泊松通常低估平局/低比分1-3个百分点,可手动把平局概率上调2个百分点(从胜负两边各扣1)

## 6. 复盘指标(无脚本时手算)

```
命中率 = 命中注数 / 已结算注数
Brier  = Σ(主观概率 − 结果)² / n     结果: 命中=1, 未中=0
模拟ROI = Σ(命中? 赔率−1 : −1) / n
校准检查: 按主观概率分组(<45%, 45-60%, 60-75%, ≥75%),比较组内平均声称概率与实际命中率
```
Brier基准: 0.25=瞎猜, <0.20=有判断力。样本<30注不下结论,<50注不改方法。
